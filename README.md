# 📊 THE 10 LARGEST POPULATIONS IN EUROPE (2024)

## 🎯 Objetivo del Proyecto
Analizar e identificar los 10 países más poblados de Europa en el año 2024, evaluando las métricas clave de población a partir de datos globales.
